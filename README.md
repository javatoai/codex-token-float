# Codex Token Float

Codex Token Float 是一个桌面悬浮计数器。使用 Codex 时，抬眼就能看到今天用了多少 Token，想看细节时也可以随手展开。

## 下载与打开

打开 [便携版下载页](https://github.com/javatoai/codex-token-float/releases/latest)，选择对应电脑的压缩包并解压。

- **Windows x64** 双击解压后的 `codex-token-float.exe`。
- **macOS 13 或更新版本** 按电脑选择 Apple 芯片版或 Intel 芯片版，将「Codex Token Float」拖到「应用程序」后打开。

## 日常使用

- **弹框视图** 平时只显示今日总量。鼠标悬停或轻点「今日」，可在下方展开明细。
- **卡片视图** 常驻显示完整的用量明细。
- 右键悬浮窗可切换视图或立即刷新。窗口始终置顶，可以拖到顺手的位置，下次打开时会恢复。
- 从 Windows 托盘或 Mac 菜单栏的应用图标，可显示、隐藏、立即刷新或退出。

## 看懂用量

| 显示项 | 含义 |
| --- | --- |
| 今日总 Token | 当天的输入和输出总用量，按四位分组显示，例如 `1,2345,6789`。 |
| 输入总量 | 包含命中缓存和未命中输入。有缓存写入用量时会单独列出。 |
| 输出总量 | 分别列出推理和非推理输出。 |
| 缓存命中率 | 命中缓存的 Token 占输入总量的比例，保留两位小数。 |

用量按北京时间划分，每两秒检查一次。有新的用量记录时，数字会平滑递增。统计在本机完成，记录有缺口时会在明细中提示。
